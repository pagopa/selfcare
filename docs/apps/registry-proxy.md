# registry-proxy

> Spring Boot proxy over the public and national registries used by SelfCare (IPA, ANAC, IVASS, InfoCamere, PDND InfoCamere, National Registries/ADE, geographic taxonomies) plus the Azure AI Search indexes for institutions and onboardings.

| | |
|---|---|
| Path | `apps/registry-proxy` |
| Stack | Spring Boot 3 (parent `selc-starter-parent` 0.3.1-SNAPSHOT resolved from the Maven repository, Jakarta APIs), Spring Cloud OpenFeign, Lucene 8.11.2, Java 17, blocking |
| Type | REST microservice, multi-module Maven project (`selc-party-registry-proxy`) |
| Tenants | Both: one deployment per tenant (`selc-<env>-party-reg-proxy` for AR, `selc-<env>-pnpg-party-reg-proxy` for PNPG) |
| Infra | `infra/resources/registry-proxy/` (`{dev,uat,prod}-{ar,pnpg}`) |

## Responsibilities

- Expose IPA data (institutions, AOO, UO, categories), ANAC stations, IVASS insurance companies and geographic taxonomies.
- Proxy InfoCamere, PDND InfoCamere (and Invitalia profile), and National Registries (legal address, legal verification).
- Search institutions and onboardings on Azure AI Search and update the onboarding index (`POST /onboarding/update-index`).
- Keep local Lucene indexes fresh with scheduled refreshes (`@Scheduled` in `core`: IPA institutions/AOO/UO daily at 02:00, ANAC and IVASS every 6 hours).
- Enforce tenant isolation for tenant-owned resources (Multitenant Step 2).

## API

- No context path. Spec generated by `SwaggerConfigTest` (`app/src/test/...`) into `apps/registry-proxy/app/src/main/resources/swagger/api-docs.json`; `apim_api_bff_proxy.json` in the same folder is a reduced copy.

| Controller | Base path | Main operations |
|---|---|---|
| `InstitutionController` | `/institutions` | list, `/{id}`, `/ipa`, `/ipa/{taxCode}` |
| `AOOController`, `UOController` | `/aoo`, `/uo` | list, by code |
| `CategoryController` | `/categories`, `/origins/{origin}/categories/{code}` | IPA categories |
| `StationController` | `/stations` | ANAC stations |
| `IvassController` | `/insurance-companies` | IVASS companies |
| `GeographicTaxonomiesController` | `/geotaxonomies` | search, `/{geotaxId}` |
| `NationalRegistriesController` | `/national-registries` | `/legal-address`, `/verify-legal` |
| `InfoCamereController` | `/info-camere` | `POST /institutions` |
| `PDNDInfoCamereController` | `/infocamere-pdnd` | `/institutions`, `/institution/{taxCode}`, `/institutions/rea/{rea}` |
| `SearchController` | `/search` | `/institutions`, `/onboardings` |
| `OnboardingController` | `/onboarding` | `POST /update-index` |
| `EventController` | `/dapr` | Dapr subscribe/events/health (excluded from springdoc) |

APIM exposure:

- **Application API** (AR only): `module "apim_api_registry_proxy"` (`_modules/apim_api`) in `infra/resources/registry-proxy/{dev,uat,prod}-ar/registry-proxy.tf`, API `selc-<env>-api-bff-proxy`, base path `party-registry-proxy/v1`, spec `api-docs.json`, tenant enforcement enabled.
- **External APIs**: operation policies in `infra/resources/_modules/apim_external_api/apim.tf` and `apim_pnpg.tf` route selected operations to `selc-<env>-party-reg-proxy-ca` / `selc-<env>-pnpg-party-reg-proxy-ca`. Operations are tagged `external-v2`, `support`, `support-pnpg`, `internal-v1`. See [external-api](external-api.md#apim-exposure-external-apis).

## Data and messaging

- No MongoDB (`tenant.mongodb.required=false`).
- Lucene indexes on the local filesystem (`LUCENE_INDEX_{INSTITUTIONS,CATEGORIES,AOOS,UOS,ANAC,IVASS}_FOLDER`).
- Azure AI Search: IPA indexes, onboarding index (per tenant through `registryProxy.search`), ISTAT geotax fallback (`GEOTAX_ISTAT_FALLBACK_ENABLED`). Terraform modules `ai_search_onboarding`, `ai_search_ipa`, `ai_search_geotax` are instantiated in `registry-proxy.tf`.
- Azure Blob Storage: ANAC/IVASS source files (`BLOB_STORAGE_CONN_STRING`, `BLOB_CONTAINER_REF`, `BLOB_ANAC_FILENAME`, `BLOB_IVASS_FILENAME`); a `visura` container plus a Dapr `blobstorage-state` component are provisioned in the AR stacks.
- Redis cache (PDND results/tokens), provisioned by `_modules/dapr` (`redis_enable = true`).
- Event Hub topic `SC-Contracts` via Dapr pub/sub (`selc-eventhub-pubsub`, consumer group `party-proxy`); the handler `/dapr/events` is a no-op.

## Integrations

- External providers: IndicePA open data, ANAC (FTP or Azure Blob, `ANAC_FTP_MODE`), IVASS, InfoCamere, PDND (`PDND_BASE_URL`), PDND InfoCamere, National Registries, geographic taxonomies, Azure AI Search.
- Internal: `InstitutionRestClient` calls `institution-ms` (`SELC_INSTITUTION_URL`) propagating bearer and tenant.
- Callers (from `infra/resources`): `external-api`, `dashboard-bff`, `onboarding-bff`, `onboarding-ms`, `onboarding-cdc`, `onboarding-functions`, `institution-ms`, plus APIM. `external-api` keeps a spec copy in `apps/external-api/src/main/docs/openapi/api-selfcare-registry-proxy-docs.json`.
- Offline index feeding: [registry-proxy-runner](registry-proxy-runner.md) writes the same AI Search indexes.

## Multitenancy

- Uses `selc-commons-tenant` 2.23.0 and the shared Spring JWT security ([selfcare-commons](../libs/selfcare-commons.md)). `X-Tenant-Id` is reconciled with the verified JWT `tenant_id`; the verification key comes from `SELFCARE_TENANT_DATA_ISOLATION`; default tenant `AR` (`tenant.default`).
- Public registries (IPA, ANAC, IVASS, geotax) are global; onboarding search, National Registries, PDND credentials/caches and the optional `storages.visure` archival are tenant-scoped through the `registryProxy` registry entry.
- PNPG onboarding search is intentionally unmapped until a dedicated index exists (app README).
- Details: [apps/registry-proxy/README.md](../../apps/registry-proxy/README.md#multitenancy-step-2). Overview: [multitenancy.md](../multitenancy.md), [Step 2 architecture](../specs/MULTITENANT/Step_2/ARCHITECTURE.md).

## Build, run and test

```bash
mvn -f apps/registry-proxy/pom.xml -pl app -am clean package -DskipTests   # as in the Dockerfile
mvn -f apps/registry-proxy/pom.xml test                                   # unit tests in all modules
mvn -f apps/registry-proxy/pom.xml test -pl app -am -Dtest=SwaggerConfigTest -Dsurefire.failIfNoSpecifiedTests=false   # regenerate api-docs.json
mvn -f apps/registry-proxy/pom.xml spring-boot:run -pl app                # local run (see README; VPN needed for some providers)
mvn --projects :test-coverage --also-make verify -Pregistry-proxy,report  # coverage, as in CI
```

No Cucumber suite. `start-local.sh` and `.devcontainer/` support local runs with Dapr.

## Deployment

- Container App via `_modules/container_app_microservice`, image `selfcare-registry-proxy-ms`, probes on `/actuator/health/{liveness,readiness}`; Dapr, Redis and AI Search modules in the AR stacks.
- Workflows: `pr_registry_proxy_ms.yml` (code review), `pr_registry_proxy_infra.yml` (Terraform plan), `publish_registry_proxy_infra.yml` (infra apply on `main` / `releases/*` or manual), `trigger_release_registry_proxy.yml` (runs `release_app.yml` for `ar` and `pnpg`).
